# 🎓 STULINGO (Study + Duolingo)

**STULINGO** — это хардкорный CLI-тренажер для учебы на базе искусственного интеллекта (Claude 3 Haiku). Он объединяет методы **Active Recall** (активное припоминание) и **технику Фейнмана**, заставляя вас объяснять сложные концепции (например, химические реакции или физические формулы) своими словами.

В отличие от обычных тестов с вариантами ответов, STULINGO использует концепцию **Mastery Learning**: вы не сможете перейти к следующему вопросу, пока ИИ не подтвердит, что вы на 100% поняли текущий материал.

## ✨ Ключевые фичи

* 🧠 **Семантическая проверка (Claude API):** Алгоритм анализирует смысл вашего текста, а не просто ищет совпадения по словам.
* 🛑 **Жесткий блок прогресса:** Ошибся или упустил деталь? ИИ даст фидбек и заставит ответить на этот же вопрос заново.
* 🎨 **Стильный CLI-интерфейс:** Красивые панели, прогресс-бары и цветовая индикация прямо в терминале (спасибо библиотеке `Rich`).
* 🗂 **Простая база знаний:** Конспекты и вопросы хранятся в легком, редактируемом формате JSON.
